ТЕМА ПРОЕКТА:
Веб-сайт открытого городского киберспортивного турнира по Dota 2 "DotaArena 2026"
с интерактивной турнирной сеткой Double Elimination, пошаговой live-симуляцией
матчей, витриной официального мерча gazbloki31.ru и комплексом практических работ.

ОСНОВНЫЕ ФУНКЦИИ И ТЕХНИЧЕСКИЕ РЕШЕНИЯ:
------------------------------------------------------------------------
1. Пошаговая LIVE-симуляция сетки плей-офф (8 команд, Double Elimination):
   - Матчи разыгрываются последовательно, один за другим;
   - Пульсирующий бейдж LIVE у текущего матча, постепенная смена счёта карт;
   - Автоматический переход победителей и проигравших в следующие раунды;
   - Торжественное определение чемпиона турнира.

2. Секция официального мерча:
   - 3 белые оверсайз футболки по 1 337 рублей ("Origin", "Выбирай: я или gazbloki31.ru", "Крестовый поход");
   - Интерактивное модальное окно оформления заказа.

3. Ростер генерального партнера gazbloki31.ru:
   - Состав из 5 игроков, капитан Kirill "gazobeton" V.;
   - Досье каждого киберспортсмена в модальном окне.

4. WAI-ARIA доступность:
   - Полная навигация с клавиатуры (Tab, Enter, Space, стрелки с циклическим переходом);
   - Управление фокусом в модальных окнах (<dialog>) с возвратом на источник;
   - Семантические landmarks, headings h1-h4, aria-live, aria-describedby, aria-invalid.

5. Запрет эмодзи:
   - Проект выполнен в строгом профессиональном киберспортивном стиле;
   - Все пиктограммы реализованы на чистых векторных SVG.

------------------------------------------------------------------------
СПОСОБ ЗАПУСКА:
------------------------------------------------------------------------
1. Открыть файл `index.html` в любом современном веб-браузере (Chrome, Edge, Firefox, Safari).
2. Либо запустить через локальный статический сервер (Live Server в VS Code, npx serve, python -m http.server 8000).
3. Для перехода к практикам использовать выдвижное меню навигации или ссылки в футере.

------------------------------------------------------------------------
КОНТРОЛЬНЫЕ ШИРИНЫ АДАПТИВНОСТИ:
------------------------------------------------------------------------
- 360px  - мобильные телефоны (одноколоночный макет, компактные карточки, боковой drawer)
- 768px  - планшеты (2 колонки карточек, адаптивная таблица)
- 1024px - ноутбуки (полная разметка сетки турнира)
- 1280px+ - широкие мониторы (максимальная сетка, фоновые эффекты glow)

------------------------------------------------------------------------
ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ:
------------------------------------------------------------------------
- Для корректного запуска тега <dialog> рекомендуется браузер с поддержкой HTML5 Dialog API (Chrome 37+, Edge 79+, Firefox 98+, Safari 15.4+).
- При отключенном JavaScript весь базовый контент остаётся доступным для чтения.
