Отчёт о тестировании адаптации

  • 🔴 Проблема 1 (360px): Карточки переполнялись — фиксированный gap 1.5rem давил контент
    ✅ Исправлено: gap заменён на clamp(.75rem, 3vw, 1.5rem) через CSS-переменную --gap
  • 🔴 Проблема 2 (360px): Широкий заголовок h1 выходил за экран, текст обрезался
    ✅ Исправлено: font-size: clamp(1.5rem, 5vw, 2.8rem) — размер подстраивается под ширину
  • 🔴 Проблема 3 (768px): Навигация переполняла строку, ссылки накладывались друг на друга
    ✅ Исправлено: overflow-x: auto + flex-wrap: nowrap + scrollbar скрыт — скролл вместо переноса
  • 🔴 Проблема 4: img без max-width выходил за ширину карточки на узких экранах
    ✅ Исправлено: max-width: 100%, height: auto на всех img — изображения гибкие
  • 🔴 Проблема 5 (360px): Широкая таблица расписания выталкивала страницу горизонтально
    ✅ Исправлено: таблица завёрнута в div.table-wrap с overflow-x: auto и min-width: 500px
