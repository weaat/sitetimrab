Grid vs Flexbox

Три ключевых различия применительно к этому сайту

Сравнение технологий вёрстки

На примере DotaArena 2026 — конкретные случаи, когда Grid выигрывает у Flexbox.

Случай на сайте CSS Grid ✅ Flexbox ⚠️
Блок статистики (4 равных столбца) ✓ repeat(4, 1fr) — явно задаёт ровно 4 колонки. Ширина не зависит от содержимого ячеек. ✗ Без flex-basis и flex-shrink:0 карточки могут стать разной ширины из-за разного текста.
Карточка-акцент героя (занимает 2 колонки) ✓ grid-column: span 2 — нативно растягивает один элемент на 2 ячейки без дополнительных обёрток. ✗ Невозможно без обёртки-строки или JS-расчёта ширины. Нарушает плоскую структуру HTML.
Выравнивание карточек по высоте в ряду ✓ align-items: stretch на grid-контейнере автоматически выравнивает все ячейки строки по высоте самой высокой. ✗ Работает только в одной строке. При flex-wrap: wrap каждая строка выравнивается независимо и последняя строка может выглядеть иначе.
