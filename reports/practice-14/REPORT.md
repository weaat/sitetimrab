## 3. Нормализация поискового запроса (Этап 3)
Для исключения влияния регистра и случайных пробелов реализована функция нормализации:
```javascript
function normalizeString(str) {
  if (!str || typeof str !== 'string') return '';
  return str.trim().toLowerCase();
}
```
Нормализации подвергаются как введённая пользователем поисковая строка, так и все текстовые поля карточки (название, артикул, описание).

## 4. Объединение условий фильтрации (Этап 4)
Разработана предикативная функция `matchesFilter(card, query, category)`, объединяющая условия логическим «И»:
```javascript
function matchesFilter(card, query, category) {
  const cardCategory = card.dataset.category || '';
  const categoryMatches = (category === 'all') || (cardCategory === category);
  if (!categoryMatches) return false;

  if (!query) return true;

  const name = normalizeString(card.dataset.name || '');
  const code = normalizeString(card.dataset.code || '');
  const desc = normalizeString(card.dataset.desc || '');
  const text = normalizeString(card.textContent || '');

  return name.includes(query) || code.includes(query) || desc.includes(query) || text.includes(query);
}
```

## 5. Обновление интерфейса и состояние пустого результата (Этап 5)
- Функция `applyFilters()` вызывается на каждое событие `input` поля поиска и `click`/`change` кнопок категорий.
- Видимость карточек переключается без перезагрузки DOM через `card.style.display`.
- При `visibleCount === 0` отображается выделенный блок `#empty-results` с поясняющим текстом и кнопкой немедленного сброса фильтров.

## 6. Единое модальное окно (Этап 6)
- Вместо дублирования девяти окон в DOM создан **ровно один** контейнер модального окна:  
  `<div class="modal-dialog" role="dialog" aria-modal="true" aria-labelledby="modal-item-title">`.
- При вызове функция `openProductModal(card)` динамически считывает `dataset` активной карточки и мгновенно заполняет DOM-узлы окна (фото, заголовок, категория, характеристики, цена).

---

## 7. Управление открытием, закрытием и фокусом (Этап 7)
- **Запоминание источника:** при клике переменная `lastFocusedTrigger = triggerElement || document.activeElement` сохраняет кнопку, открывшую окно.
- **Открытие:** `modalBackdrop.hidden = false`, блокировка скролла страницы (`overflow: hidden`), перенос фокуса на кнопку закрытия окна.
- **Закрытие:**
  1. По клику на кнопку-крестик `#modal-close-btn`;
  2. По нажатию клавиши `Escape`;
  3. По клику на внешнюю затемняющую подложку `#product-modal-backdrop`.
- **Возврат фокуса:** при закрытии вызывается `lastFocusedTrigger.focus()`, что гарантирует непрерывность навигации для пользователей скринридеров и клавиатуры.
