# Отчёт о выполнении Практики 05: Карточки героев с Flexbox

**Проект:** DotaArena 2026 — Киберспортивный турнир по Dota 2  
**Авторы:** Барышев Даниил, Мисриханов Тимур, Черникова Ксения | Группа 37-ВЕБ  
**Дата:** 2026 г.  

---

## 1. Цель работы
Освоение одномерного модульного макета **CSS Flexible Box Layout (Flexbox)** для построения адаптивной галереи карточек персонажей Dota 2, выравнивания разнородного контента внутри карточек и закрепления кнопок действий в нижней части карточки.

---

## 2. Ключевые архитектурные решения

### 2.1. Контейнер галереи карточек
- Использование Flexbox с переносом строк:
```css
.heroes-container {
  display: flex;
  flex-wrap: wrap;
  gap: 1.5rem;
  justify-content: center;
}
```

### 2.2. Карточка героя и выравнивание элементов
- Внутренний контейнер карточки организован в колонку:
```css
.hero-card {
  display: flex;
  flex-direction: column;
  flex: 1 1 280px;
  max-width: 380px;
  background: rgba(255, 255, 255, 0.04);
  backdrop-filter: blur(12px);
  border: 1px solid rgba(255, 255, 255, 0.08);
  border-radius: 16px;
  padding: 1.5rem;
}
```
- **Закрепление кнопки внизу карточки:** независимо от объёма описания персонажа кнопка «Подробнее» гарантированно прижата к нижнему краю за счёт свойства `margin-top: auto`:
```css
.hero-card__btn {
  margin-top: auto;
  align-self: stretch;
}
```

### 2.3. Выделенная карточка (Featured Hero)
- Карточка ключевого персонажа турнира выделяется увеличенным базисом и яркой рамкой:
```css
.hero-card--featured {
  flex: 2 1 360px;
  border-color: rgba(220, 38, 38, 0.5);
  box-shadow: 0 0 30px rgba(220, 38, 38, 0.2);
}
```

---

## 3. Выводы
Применение Flexbox позволило гибко управлять переносом карточек на новую строку при изменении ширины вьюпорта и гарантировать аккуратную типографику и положение интерактивных кнопок при различном объёме текста.
