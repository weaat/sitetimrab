## 1. Первичное тестирование на контрольных контрольных ширинах

Тестирование проводилось в DevTools (Device Mode) на трёх ключевых разрешениях:
- **360 px** (Мобильные телефоны / узкий экран)
- **768 px** (Планшеты / вертикальная ориентация)
- **1280 px** (Десктоп / широкоформатные экраны)

### Список выявленных проблем (до адаптации):

1. **Проблема 1 (360px) — Переполнение карточек:**  
   Фиксированный `gap: 1.5rem` и жёсткие проценты сжимали карточки, вызывая переполнение текста.
2. **Проблема 2 (360px) — Выход крупных заголовков за пределы экрана:**  
   Заголовок `h1` с фиксированным размером в пикселях не помещался на экранах 360px и обрезался.
3. **Проблема 3 (768px) — Наложение пунктов навигации:**  
   Горизонтальное меню на планшетах и телефонах ломалось при переносе, перекрывая соседние элементы.
4. **Проблема 4 (Все разрешения) — Негибкие изображения:**  
   Изображения без `max-width: 100%` выходили за границы своих родительских контейнеров.
5. **Проблема 5 (360px) — Горизонтальный скролл страницы из-за таблицы:**  
   Широкая таблица расписания матчей распирала весь `body`, создавая нежелательный скролл страницы.

## 2. Применённые решения и исправления

| Элемент / Проблема | Применённое исправление | Код решения |
|---|---|---|
| **Гибкие отступы и шрифты** | Применение функции `clamp()` | `font-size: clamp(1.5rem, 5vw, 2.8rem);` <br> `--gap: clamp(.75rem, 3vw, 1.5rem);` |
| **Hero-секция** | Переключение на вертикальный стек на узких экранах | `@media (max-width: 768px) { .site-header { flex-direction: column; text-align: center; } }` |
| **Адаптивная навигация** | Горизонтальный скролл с touch-прокруткой без полосы прокрутки | `overflow-x: auto; -webkit-overflow-scrolling: touch; scrollbar-width: none;` |
| **Гибкие карточки** | Flex-grow с базовой шириной и переходом в 1 колонку | `@media (max-width: 768px) { .hero-card { flex: 1 1 100%; max-width: 100%; } }` |
| **Таблица расписания** | Контейнер `.table-wrap` с локальным `overflow-x: auto` | `.table-wrap { overflow-x: auto; -webkit-overflow-scrolling: touch; }` |
| **Изображения** | Ограничение ширины родителем | `img { max-width: 100%; height: auto; object-fit: cover; }` |

## 3. Проверка масштабирования (200% Zoom)

При масштабировании браузера до **200%**:
- Текст масштабируется плавно благодаря относительным единицам (`rem`, `vw`, `clamp()`).
- Элементы не накладываются друг на друга, так как контейнеры не имеют жёсткой фиксированной высоты (`height: auto`).
- Кнопка действия в карточках остаётся прижатой к низу благодаря `margin-top: auto`.
- Доступность с клавиатуры (фокус через `Tab`) сохранена на всех разрешениях.
