## 1. Проектирование схемы областей (Этап 1)
Для блока «Полезная информация» спроектирована четырёхчастная сетка:
1. **`intro`** — Заголовок и вводное описание регламента для участников.
2. **`content`** — Основной текстовый блок с техническими правилами проведения матчей.
3. **`sidebar`** — Панель ключевых напоминаний (чек-ин, верификация, девайсы).
4. **`action`** — Блок действий (кнопки регистрации команды и загрузки PDF).

## 2. Схема расположения областей (Этапы 4, 5, 8)

### Схема для широких экранов (Desktop, ≥769px):
```
+-----------------------------------------------------------+-----------------------------------+
|                        intro (grid-area: intro, span 2)                                       |
+-----------------------------------------------------------+-----------------------------------+
|               content (grid-area: content)                |    sidebar (grid-area: sidebar)   |
|            Широкая область: minmax(0, 2fr)                |    Сайдбар: minmax(240px, 1fr)     |
+-----------------------------------------------------------+-----------------------------------+
|                        action (grid-area: action, span 2)                                     |
|             align-self: center (вертикальное центрирование)                                   |
+-----------------------------------------------------------------------------------------------+
```

CSS-правило:
```css
.info-grid {
  display: grid;
  grid-template-areas:
    "intro   intro"
    "content sidebar"
    "action  action";
  grid-template-columns: minmax(0, 2fr) minmax(240px, 1fr);
  gap: 1.5rem;
}
```

### Схема для мобильных устройств (Mobile, ≤768px):
```
+-----------------------------------------------------------+
|               intro (grid-area: intro)                    |
+-----------------------------------------------------------+
|              content (grid-area: content)                 |
+-----------------------------------------------------------+
|              sidebar (grid-area: sidebar)                 |
+-----------------------------------------------------------+
|              action (grid-area: action)                   |
+-----------------------------------------------------------+
```

CSS-правило:
```css
@media (max-width: 768px) {
  .info-grid {
    grid-template-areas:
      "intro"
      "content"
      "sidebar"
      "action";
    grid-template-columns: 1fr;
    gap: 1.2rem;
  }
}
```

## 3. Назначение областей и выравнивание (Этапы 3, 6, 7)

1. **Именование через `grid-area`:**
   Каждому дочернему элементу назначено семантическое имя:
   - `.info-intro { grid-area: intro; }`
   - `.info-content { grid-area: content; }`
   - `.info-sidebar { grid-area: sidebar; }`
   - `.info-action { grid-area: action; }`

2. **Применение `minmax(0, 2fr)` и `minmax(240px, 1fr)`:**
   - `minmax(0, 2fr)` гарантирует, что область контента получает вдвое больше доступного пространства, чем сайдбар, а минимальный порог `0` исключает переполнение трека длинными строками.
   - `minmax(240px, 1fr)` удерживает ширину сайдбара не менее 240px, сохраняя читаемость списков.

3. **Эффект `align-self: center`:**
   - По умолчанию в CSS Grid элементы растягиваются на всю высоту своей строки (`stretch`).
   - Для области `.info-action` задано `align-self: center`, что центрирует панель с кнопками по вертикали и предотвращает её неестественное вытягивание при длинном контенте.

4. **Тест на удвоение контента (Этап 7):**
   - Текст в блоках `content` и `sidebar` был удвоен в 2 раза: строки сетки с автоматическим расчётом высоты (`auto` / `min-content`) плавно расширяются вниз, не обрезая информацию и не нарушая порядок соседних секций.
