# Отчёт о выполнении Практики 07: Двумерные сетки CSS Grid

**Проект:** DotaArena 2026 — Киберспортивный турнир по Dota 2  
**Авторы:** Барышев Даниил, Мисриханов Тимур, Марьин Вадим | Группа 37-ВЕБ  
**Дата:** 2026 г.  

---

## 1. Цель работы
Перевод ключевых секций сайта на двухмерную модульную сетку **CSS Grid** (`display: grid`), настройка автоматического размещения колонок с помощью функций `repeat()` и `minmax()`, выделение ключевого элемента через `grid-column: span 2` и сравнительный анализ CSS Grid с Flexbox.

---

## 2. Реализованные блоки на CSS Grid

### 2.1. Сетка карточек участников турнира (`.teams-grid`)
- Использована адаптивная раскладка без медиа-запросов:
```css
.teams-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 1.5rem;
  align-items: stretch;
}
```
- Преимущество: браузер автоматически вычисляет количество колонок в строке в зависимости от доступной ширины экрана, не требуя ручной настройки брейкпоинтов.

### 2.2. Сетка карточек героев (`.heroes-grid`)
- Базовая сетка карточек:
```css
.heroes-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 1.25rem;
  align-items: stretch;
}
```
- Выделенная карточка главного маскота турнира (`.hero-card--featured`):
```css
.hero-card--featured {
  grid-column: span 2;
}

@media (max-width: 768px) {
  .hero-card--featured {
    grid-column: span 1;
  }
}
```

### 2.3. Сетка числовых показателей турнира (`.stats-grid`)
```css
.stats-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 1.25rem;
}

@media (max-width: 768px) {
  .stats-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (max-width: 480px) {
  .stats-grid {
    grid-template-columns: 1fr;
  }
}
```

## 3. Сравнительный анализ: CSS Grid vs Flexbox

| Критерий | CSS Grid (Практика 07) | Flexbox (Практика 05 / 06) |
|---|---|---|
| **Размерность сетки** | Двумерная система (управляет одновременно строками и колонками). | Одномерная система (управляет размещением вдоль одной оси за раз). |
| **Выравнивание карточек** | Строгое выравнивание по колонкам вне зависимости от длины контента соседей. | Элементы на последней строке могут растягиваться неровно при `flex-wrap: wrap`. |
| **Управление разметкой** | Вся сетка настраивается на родительском контейнере (`grid-template-*`). | Поведение распределяется между родителем (`flex`) и детьми (`flex: 1 1 auto`). |
| **Акцентные блоки** | Простое расширение ячеек через `grid-column: span N` и `grid-row: span N`. | Требует ручной регулировки `flex-basis`, `width` и медиа-запросов. |
| **Идеальное применение** | Каркасы страниц, галереи карточек фиксированной формы, сложные сетки дашбордов. | Панели навигации, кнопки с иконками, центрирование элементов, внутренности карточек. |

---

## 4. Выводы
Внедрение CSS Grid позволило упростить CSS-код, избавиться от лишних промежуточных медиа-запросов для выравнивания рядов карточек и обеспечить идеальную геометрию сетки на любых экранах.
