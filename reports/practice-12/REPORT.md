# Отчёт о выполнении Практики 12: Динамический рендеринг данных

**Проект:** Киберспортивный турнир «DotaArena 2026»  
**Студенты:** Барышев Даниил, Мисриханов Тимур, Марьин Вадим  
**Группа:** 37-ВЕБ  
**Версия проекта:** `versions/pr-12/index.html` + `versions/pr-12/js/script.js`  

---

## 1. Подключение скрипта (Этап 1)
- Файл `js/script.js` подключен перед закрывающим тегом `</head>` с обязательным атрибутом `defer`.
- В первой строке скрипта включён строгий режим `'use strict';`.

---

## 2. Описание данных проекта (Этап 2)
- Создан объект `project` со свойствами: `name`, `date`, `location`, `game`, `prizePool`, `format`, `organizer`.
- Создан массив `teamsData` из 8 команд турнира (включая ростер `gazbloki31.ru`), где каждый объект имеет строго единообразный набор ключей (`id`, `name`, `tag`, `region`, `mmr`, `captain`, `rosterCount`, `tier`, `foundedYear`, `status`).

---

## 3. Подготовка HTML-контейнера (Этап 3)
- В `index.html` оставлен пустой динамический контейнер `#teams-container`. Статические карточки удалены для исключения дублирования.
- Добавлен шаблон пустого состояния `#teams-empty` с атрибутом `hidden`.
- Добавлен элемент счётчика записей `#teams-count`.

---

## 4. Функция генерации одной карточки (Этап 4)
- Написана функция `createTeamCard(team)` на Template Literals.
- Все текстовые поля экранируются вспомогательной функцией `escapeHtml` для защиты от XSS.
- Расчёты отделены от генерации DOM.

---

## 5. Отрисовка массива (Этап 5)
- Массив отображается в контейнере через комбинацию методов `map` и `join('')`.
- Счётчик количества элементов `#teams-count` обновляется автоматически.
- При нулевой длине массива показывается понятное сообщение `#teams-empty`.

---

## 6. Функции преобразования (Этап 6)
- Реализованы чистые функции:
  - `formatCurrency(amount)` — форматирование денежных сумм в рублях с разделителями;
  - `formatMMR(mmr)` — форматирование рейтинга с суффиксом MMR;
  - `formatDate(isoDate)` — форматирование дат в локализованную строку.
- Функции протестированы в Console на 5 тестовых значениях.

---

## 7. Реакции пользователя (Этап 7)
- Добавлены 2 реакции на действия пользователя через `addEventListener` и `classList`:
  1. Выделение карточки команды по клику с переключением класса `team-card--selected` и бейджа «Выбрано»;
  2. Переключение фильтрации каталога (Все, СНГ, Западная Европа, Топ MMR) и переключение компактного режима сетки.

---

## 8. Проверка устойчивости (Этап 8)
- Введена строгая проверка `if (!container) return;`. При отсутствии элемента контейнера в DOM скрипт безопасно завершает выполнение без выброса исключений TypeError.
