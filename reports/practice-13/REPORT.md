## 2. Связывание элементов через WAI-ARIA (Этап 2)
Для обеспечения полной доступности (Accessibility) для экранных дикторов (Screen Readers) настроены стандартные ARIA-роли:
- Контейнер кнопок: `role="tablist"` с описанием `aria-label="Разделы регламента турнира DotaArena 2026"`;
- Каждая кнопка: `role="tab"` с уникальным `id="tab-[категория]"` и ссылкой `aria-controls="panel-[категория]"`;
- Каждая панель: `role="tabpanel"` с соответствующим `id="panel-[категория]"` и обратной ссылкой `aria-labelledby="tab-[категория]"`.

## 3. Начальное состояние и фокус (Этап 3)
- По умолчанию активна первая вкладка:
  - `tab-format`: `aria-selected="true"`, `tabindex="0"`;
  - `panel-format`: отображается (`removeAttribute('hidden')`), доступна для фокуса через `tabindex="0"`.
- Неактивные вкладки:
  - `aria-selected="false"`, `tabindex="-1"` (выведены из последовательности перехода по Tab внутри tablist согласно спецификации W3C Tabs Pattern);
  - Связанные панели скрыты атрибутом `hidden`.

## 4. Реализация переключения (Этап 4)
- Переключение реализовано через единый делегированный слушатель события `click` на родительском контейнере `tablist`:
```javascript
tablist.addEventListener('click', (event) => {
  const clickedTab = event.target.closest('[role="tab"]');
  if (!clickedTab) return;
  const targetIndex = tabs.indexOf(clickedTab);
  if (targetIndex !== -1) activateTab(targetIndex, false);
});
```
- Функция `activateTab(index)` централизованно сбрасывает старое состояние и активирует нужные атрибуты без дублирования обработчиков.

## 5. Полная поддержка клавиатурной навигации (Этап 5)
В обработчике `keydown` реализовано предсказуемое управление клавишами:
- **`ArrowRight`**: переход к следующей вкладке с автоматическим циклическим переносом `(index + 1) % tabs.length`;
- **`ArrowLeft`**: переход к предыдущей вкладке с циклическим переносом `(index - 1 + tabs.length) % tabs.length`;
- **`Home`**: мгновенный переход на первую вкладку;
- **`End`**: мгновенный переход на последнюю вкладку;
- **`Enter` / `Space`**: активация выбранной вкладки;
- Фокус автоматически перемещается на активную кнопку через `tabs[newIndex].focus()`.

## 7. Анимация и prefers-reduced-motion (Этап 7)
- Настроены плавные переходы прозрачности (`opacity`) и высоты/смещения продолжительностью `0.24s–0.28s`, не препятствующие быстрому чтению.
- Добавлено медиа-правило для пользователей с синдромом укачивания:
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.001ms !important;
    transition-duration: 0.001ms !important;
  }
}
```

## 8. Проверка доступности (Этап 8)
- Компонент протестирован на навигацию исключительно клавиатурой (клавиши Tab, стрелки, Enter, Space, Home, End): фокус не теряется и следует логичной структуре.
